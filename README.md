# homebrew-tap

Homebrew tap for Josh Quinn's tools.

| Tool | Install | What it is |
|---|---|---|
| [fu](https://github.com/josh-quinn/fu) | `brew install josh-quinn/tap/fu` | Park ideas mid-session, file them under the job you're on, and resume Claude Code or Copilot sessions later. Run `fu --install-skill` once afterwards. |
| [ali](https://github.com/josh-quinn/ali) | `brew install --cask josh-quinn/tap/ali` | Create, find and organise shell aliases without touching .zshrc. |
